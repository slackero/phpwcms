# Captcha Assets (`inc_captcha`)

This directory contains background image textures and TrueType fonts used by phpwcms's CAPTCHA generator (`img/captcha.php` and `SPAF_FormValidator`).

## Contents

- **Background textures**: `01.png` – `12.png`, `100.png`, `101.png`
- **Fonts**: `solmetra1.ttf`, `solmetra2.ttf`, `solmetra3.ttf`, `solmetra4.ttf`
